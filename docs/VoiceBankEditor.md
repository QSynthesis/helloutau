# 音源编辑器的计划

本文档规定第六阶段「兼容周边」中原音设定编辑器（音源编辑器）的结构、实施顺序与各步的验收标准。音源的数据、编辑层、保存与磁盘变化的规则已在 [`Editing.md`](Editing.md)「音源是第二种文档」中确定并实现，本文只涉及界面。**标为「待定」的各项须由作者决定后才开始实现**，汇总在末尾。

## 原则

- **音源是独立的文档，编辑器是独立的窗口**（作者决定）。与 UTAU 不同：UTAU 的原音设定从工程的音源设置进入，是附属于工程的对话框；HelloUtau 中音源与工程并列，一个窗口编辑一个音源，可以不打开任何工程而单独打开，有自己的撤销、保存与未保存标记。
- 第三阶段的界面原则（[`Widgets.md`](Widgets.md)「原则」）全部沿用：拖动中只改变视图，释放时以一个事务写入，Esc 放弃；每种编辑都有领域函数与命令；界面只把手势转换为函数调用。
- **写回不改变未编辑的内容**：由保存函数保证（`Editing.md`「读写的保证」），界面不得为显示而改动数据。例如未收录的 wav 只在表中列出，用户同意收录后才插入条目。
- **磁盘变化不遗漏**：窗口打开期间持有 `VoiceBankCheckScheduler`，按 `Editing.md`「磁盘变化的处理」提示用户。

## 参考实现的取舍

调查 OpenUtau（`SingersDialog`、`OtoPlot`）与 QSynthesis（`VoiceBankTab`、`WaveformArea`），结果如下：

| 方面 | OpenUtau | QSynthesis | 采用 |
|---|---|---|---|
| 窗口 | 与歌手浏览合在一个对话框里，只能选已安装的歌手 | 与工程并列的标签页，按文件夹打开 | 独立窗口，按文件夹打开（见「结构」） |
| 五个值的编辑 | 不能拖动；指针悬停处按 1–5 设值 | 五条线都能拖动，悬停加粗；F1–F5 在指针处设值 | 两者都要：拖动，另有键盘在指针处设值 |
| 移动偏移量 | 其余各值在绝对时间上不动 | 同左 | 同左（两者一致） |
| 负的 cutoff | 一律写成负数 | 保持原来的符号，结果非法时改为正数 | 保持原来的符号 |
| 波形之外 | 梅尔频谱图，叠加 frq 的 F0 | 叠加 frq 曲线，无频谱 | 频谱与 F0 作为单独一步 |
| 条目表 | 只能改五个数值，有按别名搜索，无增删 | 全部单元格可编辑，有复制、删除；缺 wav 的行标红；无搜索、排序 | 全部可编辑，加搜索、排序、增删、批量；缺 wav 与未收录的行标出 |
| 多个目录 | 表中一列「Set」 | 每个目录一个子标签页 | 左侧目录树，右侧所选目录的条目 |
| 试听 | 整个 wav | 整个 wav，可拖动进度 | 整个 wav、偏移量至 cutoff 一段、以重采样器试合成 |
| 撤销 | 无 | 有，一次拖动一个步骤 | 编辑层已有 |
| 音源信息 | readme 交给系统编辑器；子音源另有对话框 | 名字、作者、readme、`prefix.map` 在窗口内编辑 | 窗口内编辑 |
| 外部修改 | 文件监视，重新读取 | 文件监视，刷新行 | 编辑层已有的检查与提示 |

须避免的问题：QSynthesis 保存时丢失行序、把每个未收录的 wav 写成空条目、删除空的 `oto.ini`、丢弃无法解析的行；OpenUtau 没有撤销，数字写法随区域设置而变。这些在 HelloUtau 的保存函数中都已避免。

## 结构

### 窗口与打开方式

- **音源窗口**（`VoiceBankWindow`）与工程窗口（`MainWindow`）并列，由 `Editor` 一并管理；一个窗口一个音源，不用标签页。同一音源（按规范化的路径）只开一个窗口，再次打开即激活已有的窗口。
- 打开：
  - 「文件 → Open Voice Bank...」选择文件夹，工程窗口与音源窗口都有此命令；
  - 工程窗口的「编辑工程的音源」：打开该工程所用的音源，已开则激活（作者决定）；
  - 卷帘中从音符跳到它所用的条目：打开音源窗口并选中该条目（作者决定，第 8 步）；
  - 「Open Recent」（作者决定，同 VS Code）：一个菜单，先列最近的工程，分隔线后列最近的音源，各最多 10 个；再一条分隔线后是「More...」，以命令面板的形式列出全部记录（各保留最多 50 个，可搜索），最后是「Clear Recent」。两种窗口的菜单相同，任一窗口都能打开两种文档。
- 未确定编码的目录，打开时以 `VoiceBankCharsetDialog` 逐目录询问，与打开工程时相同。
- 保存（Ctrl+S）、另存为、关闭时询问保存、撤销与重做、标题栏的未保存标记，规则见 `Editing.md`「保存状态」「另存为」。
- 保存后，使用该音源的已打开工程重建映射（`Editing.md`「音源保存后的处理」）。

### 布局

作者决定：

- 上半部分：左侧为目录树（根目录与各子目录，另有「全部」），右侧为条目表，列出所选目录的条目；表的上方是搜索框。
- 下半部分：波形区，横贯窗口宽度，显示所选条目的 wav 与五个值。
- 右侧是可隐藏的停靠面板「音源信息」：名字、图片、作者、网站等 `character.txt` 的内容，`readme.txt`，`prefix.map` 表。
- 状态栏显示指针处的时间与磁盘状态的提示。

### 条目表

- 列：目录（目录树选「全部」时显示）、文件名、别名、偏移量、辅音部、cutoff、先行发声、重叠。
- 所有单元格都可编辑，一次编辑一个撤销步骤；数值按 `Editing.md` 的规则保留原有写法。
- 行的标记：
  - wav 已不存在的条目；
  - 别名与同一 wav 的其他条目重复（编辑层会拒绝，表中标出原因）；
  - 未收录的 wav：以另一种样式列在表中，不是条目，右键或按钮收录（`includeAudio`）。
- 搜索（别名、文件名）、排序（显示用，不改变文件中的顺序）。
- 多选后的操作：删除、复制（为同一 wav 加一条别名不同的条目）、批量设值等（见第 7 步）。

### 波形区

- 波形按像素取最小值与最大值绘制，缩放时重新取样并缓存。
- 五个值的画法沿用两个参考实现一致的做法：偏移量以前与 cutoff 以后为遮盖区，辅音部为另一色区域，先行发声与重叠各一条竖线，另画出这些值决定的包络。颜色为样式表可设的属性，与卷帘相同。
- 拖动线或区域边界改变该值，松开时写入。拖动偏移量时其余值在绝对时间上不动。
- 键盘在指针处设值（作者决定，同 OpenUtau）：1 偏移量、2 重叠、3 先行发声、4 辅音部、5 cutoff，可在快捷键设置中更改。
- cutoff 保持原来的符号（作者决定，同 QSynthesis）：原为负数（从偏移量起算的长度）则写负数，原为正数（从 wav 末尾起算）则写正数；新条目写负数。
- 缩放以指针为中心，与卷帘的手势相同；横向滚动。

### 试听

- 播放整个 wav、只播放偏移量到 cutoff 的一段、从指针处播放。
- 以设置中的重采样器对该条目试合成一个音符，用于检查参数在合成中的效果。音高与长度可调（作者决定）：波形区旁有两个小控件，音高默认取 `prefix.map` 中指向该目录的音高，没有则取 C4；长度默认一拍。

## 实施步骤

每一步都以自动测试覆盖窗口的命令与手势所调用的领域函数；界面的手感由作者试用验收。

### 第 1 步：窗口骨架与条目表（只读）

- `VoiceBankWindow`：打开文件夹、编码询问、标题与未保存标记、保存、另存为、关闭时询问、撤销与重做、菜单由 QActionKit 清单生成、命令面板。
- 条目表显示全部条目与未收录的 wav，目录筛选与搜索，行的标记。
- 磁盘变化：持有调度器，弹窗与不打断的提示按 `Editing.md` 的两类处理，「重新读取全部」命令。

**验收标准**：打开夏语遥音源的副本（多目录、`prefix.map`、Shift_JIS 的 readme），表中条目与 `voicedit get` 的结果一致；在外部修改 `oto.ini` 后窗口弹窗，重新读取后表格更新，撤销恢复。

**进度**（2026-09-29）：
- 编辑层：
  - `VoiceBankDocument` 持有会话，按 `Editing.md`「保存状态」判断是否未保存，并负责打开时记下所选的编码、保存、另存为，以及检查磁盘和重新读取；
  - `EditSession::stepsDiscarded` 报告被新提交丢弃的步，工程文档同样据此处理（此前保存后撤销、再做新编辑，会误显示为已保存）。
- 窗口 `VoiceBankWindow`：
  - 由 `Editor::openVoiceBank()` 打开，同一音源只开一个窗口；工程窗口的「文件 → Open Voice Bank...」「工具 → Edit Voice Bank」进入；
  - 菜单由清单的 `helloutau.voiceBankMenu` 生成，含新建、打开、最近打开、保存、另存为（默认复制全部文件）、关闭、退出、撤销与重做、命令面板、设置；
  - 标题带未保存标记，关闭时询问是否保存。
- 左侧目录树：「All Folders」与根目录及其子目录；未能读取的目录灰显。
- 右侧条目表（`VoiceBankEntryModel`）：
  - 数值按文件原有的写法显示；可按列排序，数值按大小；
  - 缺 wav 的条目加删除线；未收录的 wav 以斜体灰字列出；
  - 搜索框只匹配文件名与别名。
- 尚未做：「Open Recent」按作者决定的形式改造（音源一并列出）、磁盘变化的提示。

### 第 2 步：条目表的编辑

- 单元格编辑、插入、复制、删除条目，收录未收录的 wav，一次操作一个撤销步骤。
- 保存后，其他程序中打开的同一 `oto.ini` 只有改动的行不同（由保存函数保证，此处以端到端测试确认）。

**验收标准**：各操作经撤销与重做后树与磁盘一致；保存后以 `voicedit` 读回，结果与界面一致；未修改的目录不重写。

### 第 3 步：波形区与五个值的拖动

- 读取所选条目的 wav，绘制波形、五个值的区域与线；缩放与滚动。
- 拖动与键盘设值；拖动中只改变视图，松开时写入。

**验收标准**：拖动后的数值与指针位置相符（测试按像素换算）；负 cutoff 按作者决定的规则处理；Esc 放弃。

### 第 4 步：试听

- 整个 wav、偏移量至 cutoff、从指针处播放；以重采样器试合成。

### 第 5 步：音源信息

- `character.txt`、`readme.txt`、`prefix.map` 的编辑；目录编码的转换与重新解读（`Editing.md`「设置编码」的两种操作）。

### 第 6 步：频谱与 F0

- 频谱图；读取 frq 等频率表，把 F0 画在波形上。频率表的生成与编辑属于「频率表」一项（移入 qfrqeditor），不在此步。

### 第 7 步（可选）：批量操作

- 作者决定三项：多行批量设值（设为同一数或加减同一数）、别名的前后缀批量改名（加、换、去）、按规则复制条目（如为每条加一个带后缀的副本）。各项的对话框细节到这一步再定。

### 第 8 步（可选）：与工程窗口的联动

- 从卷帘的音符跳到它所用的条目；在音源窗口中保存后，工程中找不到样本的标记随之更新。

## 已确定的事项

作者 2026-09-29 决定：

- **音源编辑器是独立的窗口**，音源是与工程并列的文档。
- **多个目录**：左侧目录树，右侧是所选目录的条目表。
- **布局**：条目表在上，波形区在下，音源信息为右侧可隐藏的停靠面板。
- **负的 cutoff**：保持原来的符号，新条目写负数。
- **键盘设值**：数字键 1–5。
- **最近打开**：同 VS Code，工程与音源在一个「Open Recent」中以分隔线分开，其后「More...」打开命令面板式的完整列表。
- **从工程进入**：菜单「编辑工程的音源」，以及卷帘中从音符跳到其条目。
- **试合成**：音高与长度可调，默认取目录的音高与一拍。
- **批量操作**：多行批量设值、别名的前后缀批量改名、按规则复制条目。
