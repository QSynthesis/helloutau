# 停靠面板

> 状态：设计，作者 2026-10-17 决定。尚未实现。

本文档定义工程窗口与音源窗口的停靠面板，形式为 JetBrains IDE 经典界面的工具窗口：窗口四边各有一条边栏，边栏上的按钮显示或隐藏对应的面板。

## 参考

- **jetbrains-docking-system**（<https://github.com/stdware/jetbrains-docking-system>，MIT，2024，副本位于 `.cache/jetbrains-docking-system`）：同一作者的独立实现，支持 Qt 5 与 Qt 6。四条边栏各分前后两半，每半同时显示一个面板，视图模式为 Pinned、Floating（无边框）与 Window。没有信号，也没有布局的保存与恢复。`removeWidget()` 在 Floating 模式下删除调用方的控件，Window 模式的窗口在 `DockWidget` 析构后泄漏。为了在浮动窗口中使用快捷键，它在 Qt 6.7 以上重新声明 `QApplicationPrivate` 以修改其私有成员 `active_window`。
- **qtmediate 的 `CDockFrame`**（qsynthesis-revenge 的 `src/libs/qtmediate/frontend/widgettools`，只支持 Qt 5）：前者的前身，有信号与按面板的菜单。DiffScope 以它停靠轨道面板，并以 JSON 保存布局（`IProjectWindow.cpp`）。

**两者只作为设计参考，代码在本仓库中重写**（作者 2026-10-17 决定），以避开上述缺陷与私有接口。

## 结构

- **只有一个公开头文件**（作者 2026-10-17 决定）：`helloutau/Widgets/DockFrame.h`，位于 `HelloUtauWidgets`。边栏、面板外框、浮动窗口与拖动都是实现细节，放在源文件中。
- `DockFrame` 是窗口的中央控件，内含调用方的中央控件与四边的面板。布局为「左 | 上 / 中央 / 下 | 右」：左右两边占满高度，上下两边只占中央一列。**参数区与轨道区的时间轴须与卷帘对齐**，上下两边若占满宽度，打开左右面板时它们就与卷帘错位。
- 每条边分前后两半，每半同时显示一个面板，两半同时显示时以分隔条分开，同 JetBrains。同一半中显示另一个面板时，原来的面板隐藏。
- 面板以字符串 ID 标识，例如 `helloutau.parameters`。ID 用于保存布局与对应动作，不显示给用户。
- `DockFrame` 拥有面板及其浮动窗口与独立窗口，析构时一并销毁。`takePanel()` 取出面板的内容而不销毁它。
- 信号：面板的显示与隐藏、移动、视图模式的改变。查看菜单中的勾选状态与布局的保存都依据这些信号。

## 视图模式

| 模式 | 行为 |
|---|---|
| Dock Pinned | 占据所在边的空间，中央控件随之缩小 |
| Dock Unpinned | 显示时覆盖在中央控件之上，焦点移出面板时自动隐藏 |
| Floating | 无边框的 `Qt::Tool` 窗口，停留在所属窗口之上。以面板外框的标题行拖动，以边缘缩放，二者由 `QWindow::startSystemMove()` 与 `startSystemResize()` 交给系统完成，不自行计算几何（作者 2026-10-17 决定） |
| Window | 带系统边框的普通窗口 |

- Floating 与 Window 的标题行与停靠时相同，因此没有另行设计的标题栏。[`Widgets.md`](Widgets.md) 的「不做自定义标题栏」指主窗口，与此不冲突。
- 视图模式由面板外框的选项菜单切换。不进入 Pinned 的模式记住各自的几何，再次切换时恢复。

## 快捷键

**不使用 Qt 的私有接口。** Floating 与 Window 是独立的顶层窗口，`Qt::WindowShortcut` 的动作只在其所关联控件所在的窗口活动时触发。所属窗口因此把自己的 QActionKit 动作也加到每个独立出去的面板窗口上（`QWidget::addActions()`），面板窗口活动时快捷键照常可用（作者 2026-10-17 决定）。

- 每个面板有一个显示或隐藏它的动作，定义在提供该面板的清单中，因此可以在键位设置中绑定快捷键，同 JetBrains 的 Alt+数字。
- 焦点在面板中时，Esc 把焦点交还中央控件，Dock Unpinned 的面板随之隐藏。

## 面板外框

每个面板有一行标题：左侧为标题，其后是面板自己的工具栏（可选，来自 QActionKit 的布局），右侧为选项菜单与隐藏按钮。选项菜单包含四种视图模式与「移到」左、右、上、下。外观由主题的样式表决定（[`Theme.md`](Theme.md)），不写死颜色。

边栏按钮显示图标与标题，左右边栏上的文字竖排。按钮可以拖到另一条边栏或另一半上，拖到边栏之外不改变位置。

## 第一批面板

作者 2026-10-17 决定：

- **工程窗口**
  - **参数区**：从卷帘的网格中移出，默认停靠在下边。左侧的参数按钮列与琴键同宽，时间轴跟随卷帘的横向滚动与缩放。只能停靠在上下两边，独立出去时时间轴仍跟随卷帘。
  - **轨道区**：默认停靠在上边。现在只有一条音符轨道，轨道区显示整首歌的音符概览与卷帘的可见范围，单击定位卷帘。实现 [`LinkedTracks.md`](LinkedTracks.md) 之后加入音频片段与链接片段。
  - 音符属性不做成面板，因为面板中的修改须即时生效，与现在对话框的确认方式不同。
- **音源窗口**：文件夹树（左）、音源信息（右）与波形（下）改为面板，条目表格为中央控件。音源信息现在注明「不浮动」，改为面板后同样可以浮动。

## 布局的保存

- 每种窗口一份，保存在 `AppSettings`（`settings.json`）的 `layout/projectWindow` 与 `layout/voiceBankWindow`，按用户而不按工程（作者 2026-10-17 决定）。
- 内容为各面板的边、半、序号、视图模式、是否显示、尺寸与独立窗口的几何，以及各分隔条的尺寸，同时保存窗口自身的几何，现在窗口大小不保存。
- 窗口关闭时保存，新窗口按最后保存的布局打开。保存的布局中不存在的面板忽略，未出现在其中的面板按其默认位置加入，因此插件的增减不使布局失效。

## 扩展点

面板是「编辑界面扩展」的第二部分（作者 2026-10-17 决定，第一部分为动作，见 [`Plugins.md`](Plugins.md)）。插件以 `PanelContribution` 登记面板：ID、标题、图标、所属窗口种类、默认位置、显示或隐藏它的动作 ID，以及为每个窗口创建内容的函数。注册表 `PanelContributionRegistry` 是 `stdc::DynamicRegistry`，由编辑器持有（`Editor::panelContributions()`），登记方式同 `ActionContributionRegistry::AddFactory`（[`Plugins.md`](Plugins.md)「注册接口」）。登记之后打开的窗口与已经打开的窗口都加入该面板，注销时从各窗口移除。编辑器自己的面板也经由同一注册表登记。
