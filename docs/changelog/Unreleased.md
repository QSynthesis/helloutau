# 未发布

记录 0.1.7 发布之后的改动。发布时本文件改名为对应的版本号，例如 `0.1.8.0.md`。条目面向用户，按简体中文界面的名称书写。

## 新增

- 频率表新增 frc（model4）与 pmk（TIPS）两种格式，可读取、生成、编辑、转换与修复，由 SynthToolSupport 插件提供。音源窗口的「F0」框同样列出这两种格式。
- 编辑频率表对话框的「检查」菜单新增「全部忽略」，放弃所有频率表的全部修正候选，帧不变。
- 音源窗口条目表的右键菜单新增「在文件资源管理器中打开」（macOS 为「在 Finder 中打开」，Linux 为「在文件管理器中打开」），打开当前行音频文件所在的文件夹并选中该文件。
- 音符属性对话框新增「其他...」按钮，与 UTAU 的「Others...」相同，以文本查看和编辑包络、颤音、音高曲线、标签等条目，以及插件写入的其他条目。写法不对的内置条目会被拒绝，UTAU 保存时会丢弃或改动的条目会给出提示。选中的音符的条目完全相同时才能编辑。
- 音符属性对话框新增「音高」下拉框，范围 C1 至 B8，与 UTAU 相同。选中的音符音高不同时不选任何一项，不改动音高。
- 工程窗口「视图」菜单新增「跟随播放头」，可选「按页」（默认）或「平滑」。平滑方式使播放头始终位于视图正中。按页方式翻页时改为平滑移动，翻页后播放头左侧留出约一个四分音符的宽度，视图还会上下滚动，使接下来的音符可见。

## 改进

- 编辑频率表对话框：
  - 工具栏最左侧新增撤销与重做按钮，图标与工程窗口相同。
  - 工具栏的检查与修正命令（检查、上一处、下一处、修正、忽略、全部修正、全部忽略）以图标显示。
  - 编辑区下方的 x3、x2、-、/2、/3、插值、重新加载、基准频率设为选区平均值改为图标按钮，名称见悬停提示。
  - 「基准频率」的标签移到输入框上方，输入框加宽。
  - 文件列表的「修正候选」一列移到「已修改」右边。
  - 编辑区的最低音从 C1 改为 C0。
  - 打开时编辑区更宽。
  - 窗口标题显示音源名，有频率表修改未保存时带星号，与音源窗口相同。
- 生成、删除、转换、编辑频率表与处理音频文件的对话框中，音频文件以文件夹树列出，子文件夹的音频文件列在其文件夹之下，文件夹默认展开。有勾选框的列表中，勾选文件夹即勾选或取消勾选其中全部文件。
- 错解的文件名还原之后，生成、删除、转换、修复、编辑频率表与处理音频文件的对话框都按还原后的名字显示文件，与音源窗口一致。编辑频率表对话框的标题栏与提示同样如此。
- 菜单项的访问键（如「设为无声(O)」中的 O）在同一菜单内不再重复，涉及工程窗口的编辑与视图菜单、音源窗口的编辑与播放菜单，以及编辑频率表对话框的编辑、检查与播放菜单。工程窗口的编辑菜单条目较多，「设置曲速」「音符属性」「音高控制」「重置」「包络」「移调」不再设访问键。
- 设置的「频率表」页与「生成频率表...」对话框中，原复选框「重新生成时只删除分析缓存，保留频率表」改为「生成频率表时，先删除已存在的频率表和分析缓存再生成」，默认勾选，行为不变，取消勾选即只删除分析缓存。
- 修饰键设置从设置的「键位映射」页移到其下新的「修饰键」页，工程窗口与频率表编辑器各一个标签页，标签页内可以滚动，「恢复默认值」位于右侧，打开时即可见。「修饰键」页的「恢复默认值」只恢复修饰键，「键位映射」页的「恢复默认值」只恢复快捷键。修饰键的下拉框不再响应鼠标滚轮，避免滚动页面时误改。已保存的修饰键设置照常保留。
- 设置对话框的页面在高度不够时可以滚动，对话框可以缩得比页面矮，较高的页面（如「频率表」）不再限制对话框的高度。页面中的一部分隐藏后，页面随之变矮，不留空白。
- Windows 安装包不再附带 Direct3D 的着色器编译器与软件 OpenGL，体积更小。
- 设置的「插件」页中，Synth Tool Support 插件的说明不再逐项列举，改为概述频率表与第三方合成工具的其他专有特性。
- 音源窗口波形区的滚轮缩放不再固定为 `Ctrl`，横向滚动与缩放的修饰键可以在设置的「键位映射 > 修饰键」页的「音源窗口」标签页中修改。

## 修复

- 编辑频率表对话框的「合成播放」与音源窗口的「合成音符」可以用小键盘的 Ctrl+Enter 触发，此前只响应主键盘的 Ctrl+Enter。
