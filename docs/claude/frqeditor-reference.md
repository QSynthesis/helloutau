# 频率表编辑器的参考实现 qfrqeditor

记于 2026-09-28。第六阶段「兼容周边」中频率表的读取、生成与编辑，以 qfrqeditor 为参考重新编写。qfrqeditor 是依据对 masao 的 frqeditor（1.26.2016.417）行为的分析重新实现的独立程序。

## 内容

- **格式**：frq（resampler.exe）、vs4ufrq（vs4u.exe）、frc（model4.exe）、pmk（tips.exe）、dio（w4u.exe）、mrq（moresampler.exe）的读写与相互转换。
- **功能**：
  - 编辑频率曲线；
  - 以各重采样器生成频率表，并试听；
  - 检查频率表并修正候选：以进程内的实现代替 `checkfrq.dll`，与原 DLL 逐帧比较约 486 万帧，候选标志全部一致；
  - 格式转换；
  - 缩略图；
  - 作为 UTAU 插件启动；
  - 简体中文界面。
- **与原版的实测对比**（作者在原版界面中操作，只用副本）：
  - pmk、dio、frc 的转换逐字节相同；mrq 只有条目顺序与写出时间戳不同。
  - 检查（C4）后全部采纳，240 个表、6520 帧改变，301 个 frq 逐字节相同。
- **尚未对比**：帧表与区段表的建立、格式转换与缩略图的其余部分，须在原版界面中实测。

## 作者确定、HelloUtau 同样遵循的事项

- **vslib 只支持 Windows 上 64 位的 1.52 及以上版本**。低于 1.52 视为不可用。1.50 起的工程格式不能被 1.40 读取这一兼容问题不予处理。32 位 vslib 的载入器只作了设计，不实现。

## 须另行解决的问题

- **pmk 没有公开资料。** TIPS（ScientistB）没有公开源码，格式的依据只有 masao 提供的非公开示例。本仓库的代码注释只引用公开资料，实现 pmk 时注释的来源如何写须由作者决定。frc 同样没有任何公开资料。详见 qfrqeditor 仓库的 `docs/20260928-public-sources.md`。
